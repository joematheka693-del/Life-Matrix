# Life Matrix — Phase 5 Stable Project

This is the clean Phase 5 upgrade built from the working Phase 4 project flow.

No ToastContext, EmptyState, toast.css, polish.css, or watchlist-upgrade.css is used.

## Added in Phase 5

- Watchlist search
- Watchlist type filter
- Watchlist status filter
- Watchlist sorting
- Episode dropdown progress for long anime/shows
- Poster URL support
- Poster upload support
- Settings export backup JSON
- Settings import backup JSON
- Safer localStorage data normalization

## Setup

```bash
npm install
npm run dev
```

If old browser data causes weird behavior, delete localStorage key:

```txt
life_matrix_data
```
